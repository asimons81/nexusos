## 6. Environment notes and limitations

- Clean install validated on Linux (Arch, GEEKOM) with Python 3.11 (wheel)
  and 3.12 (sdist). macOS/Windows clean installs remain pending the full
  A3-02 CI matrix; this manifest will be updated at the RC gate if new
  artifacts are produced.
- MCP protocol behavior verified via stdio smoke (initialize/discovery/
  status). Full client-compatibility matrix and upgrade/schema validation
  are owned by RC-03/RC-04 (card `t_cf42e1ad`) and require a release
  candidate artifact with frozen contracts.
- PyPI publication remains maintainer-only (no credentials in environment);
  release gate card `t_ca78a007` owns that step.
- The inspection UI is a single static `index.html`; no JS asset bundle is
  produced, so the wheel's `nexusos/ui/**` glob resolves to that one file.

## 7. How to reproduce

```bash
git clone https://github.com/asimons81/nexusos.git
cd nexusos
git checkout 799ecc5ff44a9544dceb0ed8c2297f9af464eaf0
uv sync
rm -rf dist build
uv run --with build python -m build
uv run --with twine twine check dist/*
sha256sum dist/*
```
