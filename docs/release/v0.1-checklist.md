## 1. Scope freeze (v0.1)

In scope for the v0.1 release train (alpha.3 → rc.1 → stable):

| Bucket | Items | Status |
|---|---|---|
| A3 hardening | A3-01 resolved findings, A3-02 platform matrix, A3-03 coverage policy, A3-04 artifacts, A3-05 contract freeze, A3-06 docs verification, A3-07 security review | **Resolved** (see §3/§10) — shipped in `v0.1.0-alpha.3` |
| RC validation | RC-01 prerelease publish, RC-02 clean-machine validation, RC-03 MCP client compat, RC-04 upgrade/schema, RC-05 contract freeze | RC-03/RC-04 resolved (manifest §5.4/§5.5); RC-01/RC-02 open (see §3) |
| Stable gates | full matrix green, reproducible build, clean install ×3 OS, MCP smoke, upgrade/rebuild, security review, no release blockers, changelog/notes, PyPI publish, signed tag, README updated | Open (see §3) |

Explicitly **out of scope for v0.1** (post-v0.1 direction; do not build):

- ingestion pipelines (web/PDF/external services)
- guarded source writes / mutation API
- embeddings and vector retrieval
- NexusOS Studio operational dashboard
- fleet memory plane
- encrypted sync / team collaboration
- hosted MCP with OAuth

Rule of thumb: no new product scope before stable. Only release-engineering,
validation, packaging, contract-freeze, documentation, and security work.

## 5. Build / package targets

- Python: 3.11 / 3.12 / 3.13 (`requires-python >=3.11`).
- OS: Linux, macOS, Windows (CI matrix; clean installs on all three at RC-02).
- Build backend: hatchling (`src/` layout). Artifacts: sdist + wheel.
- Build + check commands (A3-04):
  ```bash
  rm -rf dist build
  uv run --with build python -m build
  uv run --with twine twine check dist/*
  ```
- Wheel must contain: `src/nexusos` runtime modules, console entry point
  (`nexusos = nexusos.cli.main:main`), bundled `src/nexusos/ui/**`, metadata,
  required runtime files.
- Sdist must include: `src/nexusos/**`, `src/nexusos/ui/**`, README, LICENSE,
  CHANGELOG, ROADMAP, SECURITY, CONTRIBUTING, AGENTS, docs/, examples/
  (already declared in `pyproject.toml` `[tool.hatch.build.targets.sdist]`).
- Version must agree across: `pyproject.toml`, `src/nexusos/__init__.py`,
  README badge/status, CHANGELOG, ROADMAP, tag, release title.
- README CI badge points to the real workflow (already fixed in PR #1).

## 7. Release artifact definitions

1. **Git tag** — annotated, e.g. `v0.1.0-alpha.3`; stable gets a verified/signed
   tag (`v0.1.0`). Push to origin.
2. **GitHub release** — title matches version, notes summarize changes, test
   totals, security posture, known limitations; attaches sdist + wheel +
   checksums (SHA256).
3. **Package artifacts** — `nexusos-<version>.tar.gz` (sdist) and
   `nexusos-<version>-py3-none-any.whl` from `python -m build`; pass
   `twine check`.
4. **Checksums manifest** — `docs/release/v0.1.0-manifest.md` with file
   hashes/checksums, version strings, and smoke-test results (owned by
   t_2ff2e0fa). **DONE** — committed for the A3-01-hardened tree
   (`799ecc5`); wheel + sdist built, twine check passed, clean-env wheel
   (Py3.11) and sdist (Py3.12) smoke green, MCP stdio smoke green.
5. **PyPI (stable, RC-01)** — prerelease to TestPyPI/PyPI at rc.1; final
   publish at stable. **Maintainer-only:** no credentials in the environment;
   requires Tony's credentials/authority.
